# Vinetality Productivity and Well-being Keychain
Vinetality is a keychain that tracks productivity and well-being with tangible feedback. In order to have a physical, shape-changing representation of measured well-being, this repository provides code that allows the Arduino board to control the blooming and retracting of the flower inside the keychain.

## Libraries Used
- Servo.h: a library designed for controlling servo motors, which provides rotational forces that drives the flower in Vinetality.

## Set up
- Install the Servo library in the Arduino IDE
- Simply connect an Arduino board to a computer through a port (e.g. USB-C) and click to upload the code in the IDE

## TUI Usage
- Open Serial Monitor and start typing to trigger movement in the flower (rememebr to hit enter as this is a prototype). It should not matter what exact text is entered
- Stop entering text and wait for the flower to close
